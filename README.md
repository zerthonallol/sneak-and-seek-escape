# Sneak And Seek Escape

Продолжаем разработку игры "Побег пацана: Стелс школьник". Учитывай, что 1 часть кода находится в репозитории: https://github.com/zerthonallol/stealth-school-escape

Добавь в проект систему инвентаря, улучшенную графику, мобильное управление и полноценный живой дом с улицей.

### 5. Расширенный Инвентарь и Предметы (5-6 слотов)
Реализуй логику взаимодействия по клавише 'E' / тап на экран на расстоянии до 2.5м для следующих предметов:
1. Дневник / Записка — подсказка с кодом от сейфа.
2. Ключ от детской комнаты — отпирает дверь.
3. Отмычка / Шпилька — открывает запертые ящики стола и тумбочки.
4. Отвертка — снимает вентиляционную решетку.
5. Гаечный ключ / Кусачки — перекусывают цепь на люке подвала или решетку окна.
6. Главный ключ от парадной двери — лежит в сейфе родительской спальни.
7. Фонарик (клавиша 'F' или кнопка UI) — освещает темные зоны.
8. Будильник — можно завести и бросить, чтобы отвлечь родителей звуком.
9. Снотворное — можно подсыпать в кружку чая на кухне, чтобы усыпить одного из родителей.
10. Веревка / Простыни — для спуска из окна.

### 6. Улучшенная Графика, Освещение и Тени
- Включи в Three.js рендерере тени (renderer.shadowMap.enabled = true, PCFSoftShadowMap).
- Настрой направленный свет (DirectionalLight / «солнце» из окон) и точечные лампы в комнатах, чтобы от мебели и персонажей падали мягкие тени.
- Добавь легкий туман/дымку (Fog) для создания атмосферы домашнего триллера.

### 7. Улучшенные Модели Родителей и Живой Распорядок Дня (ИИ-рутины)
- Улучши процедурные low-poly модели Мамы и Папы (добавь детали одежды, головы, конечностей, чтобы они выглядели узнаваемо).
- Реализуй полноценный мир дома + улицы (двор перед домом или задний сад):
  - Мама: может ходить на кухню готовить суп, убираться в гостиной или выходить во двор/сад, чтобы поливать цветы из лейки.
  - Папа: может смотреть телевизор в зале на диване, читать газету за столом или ходить в туалет/ванную по расписанию.
- У родителей есть циклы жизнедеятельности, создающие окна возможностей для игрока (проскользнуть, пока батя смотрит телик, а мама поливает цветы во дворе).

### 8. Мобильное Управление (Touch Controls для телефонов)
- Автоматическое определение мобильного устройства или переключатель интерфейса:
  - Левый виртуальный стик (Virtual Joystick) для движения (WASD).
  - Зона свайпа по правому краю экрана для обзора камеры.
  - Наэкранные кнопки: Кнопка действия ("E"), кнопка приседания ("C"), бег (Shift-toggle), фонарик ("F") и инвентарь внизу экрана.

### 9. Варианты Концовок (4 Варианта)
1. Побег через Главную Дверь: Найти код от сейфа -> забрать Главный ключ -> открыть дверь -> побег.
2. Побег через Окно/Балкон: Найти отвертку -> снять решетку -> закрепить веревку -> спуститься.
3. Побег через Подвал: Найти фонарик и кусачки -> перекусить цепь на люке -> выбраться наружу.
4. Секретная концовка: Подсыпать родителям снотворное, пока они заняты своими делами (телик/цветы), забрать золотой дневник и выйти через парадную дверь.

### 10. Технические Требования
- Объедини все в единый чистый и работающий HTML-файл со встроенными Three.js (через CDN), стилями и логикой JavaScript.
- Все элементы генерируются процедурно из low-poly примитивов (BoxGeometry, CylinderGeometry), чтобы проект запускался мгновенно без внешних тяжелых ассетов.
